Privacy Policy

Last updated: 17 November 2026.

This policy explains how personal data is processed when you use the website ai-gov.network. It is written for Regulation (EU) 2016/679 (GDPR) and for Portuguese Law No. 58/2019 of 8 August, which implements the GDPR in Portugal. It describes only what this website’s code actually does.

1. Controller

The controller is LINKWITH UNIPESSOAL, LDA, NIPC 517054124. This website is operated under the brand ai-gov.network.

Privacy contact: info@ai-gov.network

This website does not name a data protection officer. Requests to exercise your rights go to the controller, at the email above.

2. Data this website actually handles

There is no user account, no contact form and no newsletter. This website does not collect payment data. Training enrolment, and any payment, take place on another website, as described below.

2.1 Technical data from a visit

When your browser requests a page, the server handles the technical data needed to deliver it and to keep the service secure: IP address, date and time, the address requested, and the browser’s user agent. The site is a Flask application. It does not keep a database of visitors. These are the operational logs of the hosting service.

2.2 Email

If you write to info@ai-gov.network, the controller receives your email address, the content of the message, and anything you include in it. The website code does not show which provider hosts that mailbox, so this policy does not name one.

2.3 Booking a session

The pages /book and /en/book can embed a scheduling calendar. The code identifies that calendar as Zoho Bookings (environment variable ZOHO_BOOKINGS_URL; the example in the code is a zohobookings.eu address). The embed script is loaded from bookings.nimbuspop.com, and the calendar is shown only when that address is configured. The details you enter there — the slot you choose and whatever fields that provider’s form asks for — are processed by that provider. This application does not store them.

2.4 Training enrolment

Training pages show a catalogue read, on the server, from a WooCommerce shop. The enrolment button opens an external address supplied by that catalogue. The page states that enrolment is completed on the website of CISODPO, the official PECB partner delivering the course. Data you submit there, including identification, contact details and any payment, is processed by that organisation under its own policy. It is not received by ai-gov.network.

2.5 Confirmation Bias Lab

On /lab, the text you type (the scenario and the two options) is sent to this website’s server and forwarded to Cloudflare Workers AI so the models can answer. The application code does not save that text after it returns the result. Do not include personal data in that text. If you do, it is processed only to produce the answer you asked for.

2.6 Audience measurement

Pages include Google Tag Manager, container GTM-5DZF35QV, through the shared template. That script can send Google technical data about the visit. The tags inside the container are not in this repository, so this policy does not list cookies or purposes that the code does not show.

The homepage, the framework pages, publications, articles, training pages, the lab and this policy also load the Cloudflare Web Analytics beacon, which measures visits in aggregate. That beacon is not included on the booking pages or on the observatory page. The observatory chart is a document embedded in /observatorio and does not add an analytics script of its own; the parent page loads Google Tag Manager.

2.7 Fonts

Pages load typefaces from Google Fonts (fonts.googleapis.com). Your browser sends Google your IP address and the page address in order to fetch the font files.

2.8 Images

When image hosting on Cloudflare R2 is configured (R2_BASE_URL), the browser requests those images from Cloudflare. Otherwise, article images use the address returned by WordPress. Either request reveals your IP address to the service that delivers the file. Articles and the training catalogue are read server to server. That call does not send the contents of a visitor form.

3. Purposes and legal bases

  • Running and securing the website. Technical logs. Legitimate interest in delivering the pages and protecting the service (Article 6(1)(f) GDPR). The interest is limited to operational logs.
  • Replying to email you send. Your address and the message. Steps taken at your request before a contract, when you ask for contact or a service (Article 6(1)(b)). Legitimate interest in answering, in other cases (Article 6(1)(f)).
  • Scheduling a session. The data the calendar asks for. Steps taken at your request before a contract (Article 6(1)(b)), carried out by the booking provider.
  • Measuring aggregate use. Technical data processed by Cloudflare Web Analytics and, depending on the tags, by Google Tag Manager. Legitimate interest in understanding which pages are used (Article 6(1)(f)), for measurement that does not use cookies. If a Google Tag Manager tag sets non-essential cookies, that operation needs consent (Article 6(1)(a) GDPR and Portuguese Law No. 41/2004). This website’s code does not show a cookie-consent banner. See Cookies below.
  • Producing the lab answer. The text you submit. Your request, when you run the analysis (Article 6(1)(b)).
  • Showing the site’s typefaces. IP address and page address, processed by Google Fonts. Legitimate interest in the visual presentation of the site (Article 6(1)(f)).

4. How long data is kept

  • Email. For as long as needed to handle the request and, where one applies, for the period of a legal duty attached to that correspondence. The code does not set a number of months or years.
  • Hosting logs. For the period the hosting provider keeps them for operation and security. That period is not defined in this repository.
  • Lab text. Not stored by this application after the response is returned.
  • Booking and enrolment data. Not stored on this website. Retention is that of Zoho Bookings and of the shop where you enrol.
  • Audience measurement. According to the settings of Cloudflare Web Analytics and of the Google Tag Manager container. This repository does not set those periods.

5. Sharing with processors

The following are the services this website’s code actually uses to operate. Personal data is not sold.

  • Railway — hosting of this application, as referred to in the code and used to publish the site. It processes technical access logs.
  • Google — Google Tag Manager (GTM-5DZF35QV) and Google Fonts.
  • Cloudflare — Cloudflare Web Analytics; Cloudflare Workers AI for the lab; Cloudflare R2 when image hosting is configured.
  • Zoho Bookings — the scheduling calendar on the booking pages, loaded through the script at bookings.nimbuspop.com when ZOHO_BOOKINGS_URL is set. The repository does not contain the contract that would classify this provider, so this policy does not go beyond what the embed does: the booking is taken in that service, and this website does not receive or store what you type there.

CISODPO is not a processor of this website. The training page says enrolment is completed on the website of that official PECB partner, and the button opens the external address from the WooCommerce catalogue. Data entered there is processed by that organisation, as its own controller.

A link to a LinkedIn profile does not, by itself, send this website a form. If you follow the link, LinkedIn’s own policy applies. LinkedIn is not embedded.

The code does not show advertising sharing of our own, other than whatever the Google Tag Manager container might do. That configuration is not in the repository, so it is not described here as if it were known.

6. International transfers

Google and Cloudflare are organisations that process data outside the European Economic Area, including in the United States. Railway hosts the application; the server region is not set in this repository, so processing may take place outside the EEA. The calendar example in the code points at a zohobookings.eu address. The live address is an environment variable, so the location of booking data depends on that configuration.

Where data is transferred outside the EEA, the transfer rests on the safeguards those providers publish, in general the European Commission’s standard contractual clauses. The processor contracts are not in this repository.

7. Your rights

Under Articles 15 to 21 of the GDPR you may ask for:

  • access to the data;
  • rectification;
  • erasure;
  • restriction of processing;
  • portability, where processing is based on consent or a contract and is carried out by automated means;
  • objection, in particular where the legal basis is legitimate interest.

Where processing is based on consent, you may withdraw it at any time. Withdrawal does not affect the lawfulness of processing before the withdrawal.

Send requests to info@ai-gov.network. We may ask for information to confirm that the request comes from the person the data is about. The time limit for a reply is one month, which can be extended under Article 12 of the GDPR.

You may lodge a complaint with the Portuguese data protection authority, the Comissão Nacional de Proteção de Dados (CNPD), at www.cnpd.pt.

The lab does not produce a decision with legal or similarly significant effects about you. It is a demonstration you start yourself.

8. Cookies

This website’s own code does not set cookies. It does not use a Flask session and it does not use the browser’s local storage for tracking.

Third parties may set cookies:

  • Google Tag Manager may set cookies, depending on the tags in container GTM-5DZF35QV. Those tags are not in the repository. This policy does not describe cookies it cannot see.
  • The Zoho Bookings calendar, when it is loaded, may set cookies of the booking provider.
  • The Cloudflare Web Analytics beacon included on the pages is built to measure visits without a cookie. The site does not add an identifier of its own to that script.

The code does not include a consent banner. Cookies that are strictly necessary to provide the service can be used without consent. Non-essential cookies, if they are switched on by the Google Tag Manager container or by the calendar, require consent beforehand. Until the container configuration is confirmed, this policy does not claim that only necessary cookies are used.

9. Security

The public site is published at https://ai-gov.network. There are no user accounts on this website. Access to messages received at the contact email belongs to the controller. This policy does not describe certifications or controls that are not in the code.

10. Changes

This policy can be updated when the website starts processing data differently. The date at the top of this page is the date of the last update. The version in force is the one published at this address.

11. Contact

info@ai-gov.network

Política de Privacidade

Última atualização: 17 de novembro de 2026.

Esta política explica como são tratados os dados pessoais de quem utiliza o sítio ai-gov.network. Aplica-se o Regulamento (UE) 2016/679 (RGPD) e a Lei n.º 58/2019, de 8 de agosto, que assegura a execução do RGPD na ordem jurídica portuguesa. Descreve apenas o que o código deste sítio faz de facto.

1. Responsável pelo tratamento

O responsável pelo tratamento é a LINKWITH UNIPESSOAL, LDA, NIPC 517054124. Este sítio é operado sob a marca ai-gov.network.

Contacto para assuntos de privacidade: info@ai-gov.network

Neste sítio não é indicado um encarregado de proteção de dados. Os pedidos de exercício de direitos dirigem-se ao responsável, pelo email acima.

2. Dados que este sítio trata de facto

Não há área de conta, não há formulário de contacto e não há newsletter. Este sítio não recolhe dados de pagamento. A inscrição em formações, e o pagamento quando existe, ocorrem noutro sítio, como se explica abaixo.

2.1 Dados técnicos da visita

Quando o navegador pede uma página, o servidor trata os dados técnicos necessários para a entregar e para a segurança do serviço: endereço IP, data e hora, endereço pedido e o agente do navegador (user agent). O sítio é uma aplicação Flask. Não tem uma base de dados de visitantes. Estes são os registos de operação do alojamento.

2.2 Correio eletrónico

Se escrever para info@ai-gov.network, o responsável recebe o endereço de email, o conteúdo da mensagem e o que nela incluir. O código do sítio não mostra qual o prestador da caixa de correio, pelo que esta política não o nomeia.

2.3 Agendamento

As páginas /book e /en/book podem incorporar um calendário de marcações. O código identifica esse calendário como Zoho Bookings (variável de ambiente ZOHO_BOOKINGS_URL; o exemplo no código é um endereço em zohobookings.eu). O script de incorporação é carregado de bookings.nimbuspop.com, e o calendário só é apresentado quando esse endereço está configurado. Os dados que aí introduzir — o horário escolhido e os campos que o formulário desse prestador pedir — são tratados por esse prestador. Esta aplicação não os guarda.

2.4 Inscrição em formações

As páginas de formação mostram o catálogo lido, no servidor, de uma loja WooCommerce. O botão de inscrição abre um endereço externo fornecido por esse catálogo. O texto da página indica que a inscrição é feita no sítio da CISODPO, parceiro oficial PECB que ministra a formação. Os dados que aí submeter, incluindo identificação, contacto e pagamento, são tratados por essa organização, segundo a política dela. Não são recebidos pelo ai-gov.network.

2.5 Laboratório (Confirmation Bias Lab)

Em /lab, o texto que escrever (o cenário e as duas opções) é enviado ao servidor deste sítio e reencaminhado para a Cloudflare Workers AI, para os modelos responderem. O código da aplicação não guarda esse texto depois de devolver o resultado. Não inclua dados pessoais nesse texto. Se os incluir, são tratados apenas para produzir a resposta pedida.

2.6 Medição de audiência

As páginas incluem o Google Tag Manager, contentor GTM-5DZF35QV, através do modelo comum. Esse script pode transmitir à Google dados técnicos da visita. As etiquetas dentro do contentor não estão neste repositório, pelo que esta política não enumera cookies ou finalidades que o código não mostra.

A página inicial, as páginas do framework, as publicações, os artigos, as formações, o laboratório e esta política carregam também o beacon da Cloudflare Web Analytics, que mede visitas de forma agregada. Esse beacon não está nas páginas de agendamento nem na página do observatório. O gráfico do observatório é um documento incorporado em /observatorio e não acrescenta um script de audiência próprio; a página que o contém carrega o Google Tag Manager.

2.7 Tipos de letra

As páginas carregam tipos de letra a partir da Google Fonts (fonts.googleapis.com). O navegador envia à Google o endereço IP e o endereço da página, para obter os ficheiros.

2.8 Imagens

Quando o alojamento de imagens na Cloudflare R2 está configurado (R2_BASE_URL), o navegador pede essas imagens à Cloudflare. Caso contrário, as imagens dos artigos usam o endereço devolvido pelo WordPress. Em qualquer dos casos, o pedido revela o endereço IP ao serviço que entrega o ficheiro. Os artigos e o catálogo de formações são lidos de servidor para servidor. Essa chamada não envia o conteúdo de um formulário do visitante.

3. Finalidades e fundamentos jurídicos

  • Operar e proteger o sítio. Registos técnicos. Interesse legítimo em entregar as páginas e proteger o serviço (artigo 6.º, n.º 1, alínea f), do RGPD). O interesse limita-se a registos de operação.
  • Responder ao email que envia. O endereço e a mensagem. Diligências pré-contratuais a pedido do titular, quando pede um contacto ou um serviço (artigo 6.º, n.º 1, alínea b)). Interesse legítimo em responder, nos restantes casos (alínea f)).
  • Marcar uma sessão. Os dados que o calendário pedir. Diligências pré-contratuais a pedido do titular (alínea b)), realizadas pelo prestador do calendário.
  • Medir a utilização agregada. Dados técnicos tratados pela Cloudflare Web Analytics e, conforme as etiquetas, pelo Google Tag Manager. Interesse legítimo em perceber que páginas são usadas (alínea f)), na medição que não usa cookies. Se uma etiqueta do Google Tag Manager colocar cookies não essenciais, essa operação depende de consentimento (artigo 6.º, n.º 1, alínea a), do RGPD e Lei n.º 41/2004). O código deste sítio não mostra um aviso de consentimento de cookies. Ver a secção Cookies.
  • Produzir a resposta do laboratório. O texto introduzido. O pedido do titular, ao executar a análise (alínea b)).
  • Mostrar os tipos de letra do sítio. Endereço IP e endereço da página, tratados pela Google Fonts. Interesse legítimo na apresentação gráfica do sítio (alínea f)).

4. Prazos de conservação

  • Email. Pelo tempo necessário para tratar o pedido e, quando exista, pelo prazo de uma obrigação legal aplicável a essa correspondência. O código não fixa um número de meses ou de anos.
  • Registos do alojamento. Pelo período em que o prestador de alojamento os conserva para operação e segurança. Esse prazo não está definido neste repositório.
  • Texto do laboratório. Não é guardado por esta aplicação após a resposta.
  • Dados de marcação e de inscrição. Não são guardados neste sítio. O prazo é o do Zoho Bookings e o da loja onde a inscrição é feita.
  • Medição de audiência. Segundo a configuração da Cloudflare Web Analytics e do contentor Google Tag Manager. Este repositório não fixa esses prazos.

5. Partilha com subcontratantes

Indicam-se os serviços que o código deste sítio utiliza de facto para funcionar. Os dados pessoais não são vendidos.

  • Railway — alojamento desta aplicação, referido no código e usado na publicação do sítio. Trata os registos técnicos de acesso.
  • Google — Google Tag Manager (GTM-5DZF35QV) e Google Fonts.
  • Cloudflare — Cloudflare Web Analytics; Cloudflare Workers AI no laboratório; Cloudflare R2 quando o alojamento de imagens está configurado.
  • Zoho Bookings — o calendário de marcações nas páginas de agendamento, carregado pelo script em bookings.nimbuspop.com quando ZOHO_BOOKINGS_URL está definida. O repositório não contém o contrato que qualificaria este prestador, pelo que esta política não vai além do que a incorporação faz: a marcação é feita nesse serviço, e este sítio não recebe nem guarda o que aí for escrito.

A CISODPO não é subcontratante deste sítio. A página de formação indica que a inscrição se conclui no sítio desse parceiro oficial PECB, e o botão abre o endereço externo do catálogo WooCommerce. Os dados aí introduzidos são tratados por essa organização, como responsável autónomo.

Uma ligação para um perfil no LinkedIn não envia, por si, um formulário a este sítio. Se seguir a ligação, aplica-se a política do LinkedIn. O LinkedIn não está incorporado.

O código não mostra partilha publicitária própria, para além do que o contentor Google Tag Manager possa fazer. Essa configuração não está no repositório, por isso não é descrita aqui como se fosse conhecida.

6. Transferências internacionais

A Google e a Cloudflare são organizações que tratam dados fora do Espaço Económico Europeu, incluindo nos Estados Unidos. A Railway aloja a aplicação; a região do servidor não está definida neste repositório, pelo que o tratamento pode ocorrer fora do EEE. O exemplo de calendário no código aponta para um endereço zohobookings.eu. O endereço em uso é uma variável de ambiente, pelo que a localização dos dados de marcação depende dessa configuração.

Quando há transferência para fora do EEE, esta assenta nos mecanismos que esses prestadores publicam, em regra as cláusulas contratuais-tipo da Comissão Europeia. Os contratos de subcontratação não estão neste repositório.

7. Direitos dos titulares

Nos termos dos artigos 15.º a 21.º do RGPD, pode pedir:

  • acesso aos dados;
  • retificação;
  • apagamento;
  • limitação do tratamento;
  • portabilidade, quando o tratamento assenta no consentimento ou num contrato e é realizado por meios automatizados;
  • oposição, em particular quando o fundamento é o interesse legítimo.

Quando o tratamento se basear em consentimento, pode retirá-lo a qualquer momento. A retirada não compromete a licitude do tratamento efetuado antes dela.

Os pedidos enviam-se para info@ai-gov.network. Podemos pedir informação para confirmar que o pedido vem da pessoa a quem os dados dizem respeito. O prazo de resposta é de um mês, prorrogável nos termos do artigo 12.º do RGPD.

Tem o direito de apresentar reclamação à Comissão Nacional de Proteção de Dados (CNPD), em www.cnpd.pt.

O laboratório não produz uma decisão com efeitos jurídicos, ou equiparáveis, sobre si. É uma demonstração que a própria pessoa aciona.

8. Cookies

O código deste sítio não grava cookies. Não usa sessão Flask nem o armazenamento local do navegador para rastreio.

Terceiros podem colocar cookies:

  • O Google Tag Manager pode colocar cookies, conforme as etiquetas do contentor GTM-5DZF35QV. Essas etiquetas não estão no repositório. Esta política não descreve cookies que não consegue ver.
  • O calendário Zoho Bookings, quando é carregado, pode colocar cookies do prestador do agendamento.
  • O beacon da Cloudflare Web Analytics incluído nas páginas está feito para medir visitas sem cookie. O sítio não acrescenta um identificador próprio a esse script.

O código não inclui uma faixa de consentimento. Os cookies estritamente necessários à prestação do serviço podem ser usados sem consentimento. Cookies não essenciais, se forem ativados pelo contentor Google Tag Manager ou pelo calendário, exigem consentimento prévio. Até a configuração do contentor ser confirmada, esta política não afirma que só são usados cookies necessários.

9. Segurança

O sítio público está publicado em https://ai-gov.network. Não há contas de utilizador neste sítio. O acesso às mensagens recebidas no email de contacto é do responsável. Esta política não descreve certificações ou controlos que não estejam no código.

10. Alterações

Esta política pode ser atualizada quando o sítio passar a tratar dados de forma diferente. A data no início desta página é a data da última atualização. A versão em vigor é a que está publicada neste endereço.
